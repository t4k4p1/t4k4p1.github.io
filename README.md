# Personal website

Published at https://t4k4p1.github.io/.

This is a single-page static website. `index.html` contains the content, `styles.css` defines the responsive layout, and `assets/` contains the images and icons. No build tools, JavaScript, external fonts, or tracking services are required.

For a local preview, run `python3 -m http.server 8767 --bind 127.0.0.1` from this directory.

GitHub Pages publishes the `main` branch from the repository root. Changes pushed to `main` update the public website.

The icons are from [Tabler Icons](https://github.com/tabler/tabler-icons), used under the MIT license in `assets/icons/LICENSE.txt`. The existing template license is retained in `LICENSE.md`.
